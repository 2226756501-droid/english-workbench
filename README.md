# 英语开口工作台

一个单文件的英语学习工作台：每日打卡、雅思 Part 2 抽卡计时、场景句型自测、词汇本、录音回听、进度日历。

打开即用。默认数据存在浏览器本地，不注册也能用；注册后可跨设备同步。

## 在线地址

- 应用版（支持手机电脑同步）：https://english-workbench-31545.app.workbuddy.host/
- 静态镜像（数据只存本机）：https://2226756501-droid.github.io/english-workbench/

## 它解决什么问题

词汇量 1686、目标是「能开口」而不是「能做题」。所以整个设计倒过来排：

- 四项全覆盖，口语占最大块 —— 听力和阅读从阶段二起步，写作最晚第 3 个月动笔
- 词汇走两条线 —— 系统推进线每天 20 个新词补词汇量，活性线只记说得出来的词
- 门槛压到 8 分钟 —— 没状态时做完底线版就算完成
- 每周可验证 —— 录音是最诚实的打卡，骗不了自己

关键区分：**被动词汇**（看到能认，服务听读，目标 6000～8000）和**主动词汇**（能说出来，服务说写，目标 2000～3000）。传统背单词只补前者，本工作台两条线分开推进。

雅思被并进来而不是另起一套：雅思口语 Part 1 就是日常话题问答，Part 2 是独自说满 2 分钟，和「能开口」是同一件事的不同档位，一鱼两吃。Part 3 是抽象话题追问（社会、科技、教育、环境），考的是展开论证的能力，是 6.5 冲 7 的分水岭，建议第 3 个月后再用。

## 功能

| 页签 | 内容 |
|---|---|
| 今日打卡 | 四步勾选、随机抽题（基础 30 题 / 进阶 15 题可切换）、1 分钟开口计时（停顿超 3 秒会提示） |
| 阶段方案 | 12 个月三阶段路线，自动判定当前阶段 |
| 雅思 | Part 2 抽卡 30 张（双计时 + 每题配套的撑时表达）、Part 3 深度问答 30 题（附词块 + 五步答题框架）、写作记录、模考分数自动算总分 |
| 发音 | 跟读训练器（自动循环朗读 + 慢速档 + 每遍留白跟读）、48 个音标速查、自然拼读规则表。均为查阅型，不占每日时间 |
| 场景句型 | 7 类 43 句，可遮英文自测、标记已掌握 |
| 词汇本 | 只记说得出来的词，带随机抽查 |
| 每日刷词 | 每天 20 个新词，认得过、不熟收进词表，进度自动往前推。顺序是**等级内随机**（不是字母序），按 A1→C1 分档推进，既有难度梯度又不会连着撞同字母的词 |
| 分级词库 | 内置 4954 词（CEFR A1–C1），带音标、中文释义、真实例句，例句均可点读并附中文译文。可按等级筛选或搜词，挑中一键加入自己的词表 |
| 录音 | 浏览器内录音回听，存本机 IndexedDB |
| 数据 | 打卡日历、JSON 导出导入 |

## 数据存在哪

默认存在浏览器的本地存储里（键值存储 + IndexedDB），**不上传任何服务器**。

在应用版网址上注册并登录后，打卡进度、词汇、句型掌握状态会自动同步到云端，手机和电脑用同一账号即可看到同一份数据。同步规则：

- 采用「最后修改优先」合并，两端都以最新一次改动为准
- 录音文件较大，仍只存在各自的本地设备，不上传
- 未登录时一切照常，只是数据不出本机

注意：静态镜像（github.io）和本地文件版无法调用云同步，页面会显示「同步不可用」，此时仍可正常打卡。

无论是否登录，都建议定期在「数据」页导出 JSON 备份。

## 技术

原生 HTML + CSS + JavaScript，无框架、无构建、无依赖，单文件约 760 KB（内置词库 527 KB + 例句译文 172 KB）。

朗读用浏览器自带的语音合成（Web Speech API），离线可用，不请求任何外部接口。

## 数据来源

- 分级词表：[Oxford 5000](https://github.com/tyypgzl/Oxford-5000-words)（CEFR 等级、音标、例句）
- 中文释义：[ECDICT](https://github.com/skywind3000/ECDICT) 开源英汉词典，77 万词条，匹配覆盖率 99.8%

构建方式见 `build_words.py`：下载两份原始数据 → 按词匹配 → 只保留词、等级、音标、首个中文义项、一条例句 → 压成 527 KB 内嵌进 HTML。运行时不请求任何外部接口。

例句的中文译文由 `translate_examples.py` 离线生成（Argos Translate 的 en→zh 模型，本地 CPU 推理，47 秒翻完 4916 条）。**译文是机器翻译，多数准确但偶尔跑偏**，页面上已标注。拿不准的句子以词条本身的中文释义为准。
